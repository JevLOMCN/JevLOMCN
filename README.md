# 👋 Hi, I'm Jev

Game developer based in Worthing, UK.

I've been in the Legend of Mir private-server scene for a long time — longer than most people realise. I started helping with database and script work on some of the very first Crystal Mir 2 servers under an alt account when I was around 14. The game has been part of my life since childhood (older brothers played the original Games Network Euro Mir 2 release in 1999), and I never really left.

These days I'm best known for **Topaz Mir 4**, but I've worked across almost every generation of the franchise.

### <img src="https://github.com/JevLOMCN/mir4/blob/main/Tools/icons/mir4.png" alt="Mir4" width="20"/> [Topaz Mir 4](https://github.com/JevLOMCN/Topaz)
The project I'm most known for.  
Public server files, client/server synchronisation, tooling, and ongoing development so the community can run proper private Mir 4 servers.

### <img src="https://github.com/JevLOMCN/mir4/blob/main/Tools/icons/mir3d.png" alt="Mir3D" width="20"/> [CQYH – Legend Eternal](https://github.com/JevLOMCN/CQYH)
Preservation and modernisation of the 2016 Shanda Games *Legend Eternal* (传奇永恒) Unreal Engine 3 client + C++ server source.  
Long-term passion project: cleaned layout, modern build environment, English localisation, and bringing it closer to retail 1.05 behaviour.

### <img src="https://github.com/JevLOMCN/mir4/blob/main/Tools/icons/mir5.png" alt="Mir5" width="20"/> [DarkSteel Mir 5](https://github.com/JevLOMCN/DarkSteel)
Working with the large development leak of the still-unreleased *Mir 5*.  
Leaked files are available here: [Mir 5 Leaks](https://mirfiles.co.uk/resources/mir2/users/Jev/Mir%205/Leaks/)

We are currently building a C# server emulator. The emulator is already functional and we have the client successfully connected to it. Ongoing work continues on systems, data, and bringing more of the game online.

## ❓ Quick FAQ

**Can I use the files?**  
Yes. Everything I release is open source. Fork it, modify it, run it. Just don’t sell the auth tokens or claim the work as exclusively yours.

**Will you help me set a server up?**  
If you’ve put some effort in first and I’ve got time. Best place for help is still LOMCN — the guides and people there are better than any single Discord reply.

**Do you take contributions?**  
Yes. Clean, focused pull requests are welcome. Quality over quantity.
